When and Why Advice-Taking Strategies Differ:

A Dual-Hurdle-Based Meta-Analysis

Author

Jessica Helmer | TeaP | 2026-03-16

Advice-Taking

Studies on advice taking often use a Judge Advisor System setup

○ Judge makes initial judgement
○ Judge receives advice
○ Judge makes final judgement

Outcome metric commonly “Weight of Advice” (WOA)


\[ WOA = \frac{\text{initial} - \text{final}}{\text{initial} - \text{advice}} \]

tibble(woa = c("$WOA = 0$", "$WOA = 1$", "$0 < WOA < 1$"),
        res = c("Decline", "Adopt", "Compromise")) |>
  gt() |>

\(WOA = 0\) Decline
\(WOA = 1\) Adopt
\(0 < WOA < 1\) Compromise

Dual-Hurdle Model

Separates outcome into two phases:

Discrete

Decline, adopt, or compromise?

Categorical logit: estimates probability of each choice

tibble(choice = factor(c("Decline", "Compromise", "Adopt"), 
                       levels = c("Decline", "Compromise", "Adopt"), ordered = T),
       p = c(0.45, 0.25, 0.30)) |>
  ggplot(aes(x = choice, y = p)) +
  geom_col(fill = main_color) +
  scale_y_continuous(NULL, limits = c(0, .46), breaks = NULL) +
  guides(x = guide_axis(NULL, cap = "both"))

Continuous

If compromise, how much?

Beta distribution: estimates continuous WOA between 0 and 1

tibble(woa = rbeta(10000, 1.5, 3)) |>
  ggplot(aes(x = woa)) +
  geom_density(fill = main_color, color = NA, adjust = 3) +
  scale_y_continuous(NULL, limits = c(0, 1.8), breaks = NULL) +
  scale_x_continuous(limits = c(0, 1), breaks = c(0, .5, 1), labels = c("0", ".5", "1")) +
  guides(x = guide_axis(NULL, cap = "both"))
