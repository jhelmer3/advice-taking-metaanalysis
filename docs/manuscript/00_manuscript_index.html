Dual-Hurdle Model

\[ \begin{aligned} \text{WOA}_i &= \begin{cases} \begin{array}{l} 1 &\text{ with } p = \eta_{A_i} \\ 0 &\text{ with } p = \eta_{D_i} \\ c &\text{ with } p = 1 - \eta_{A_i} - \eta_{D_i} \end{array} \end{cases} && \note{probabilities for each outcome}\\ \text{logit}(\eta_{A_i}) &= \alpha_{\eta_A} + \alpha_{\eta_{A_{j[i]}}} + \alpha_{\eta_{A_{k[i]}}} && \note{logit models with random effects} \\ \text{logit}(\eta_{D_i}) &= \alpha_{\eta_D} + \alpha_{\eta_{D_{j[i]}}} + \alpha_{\eta_{D_{k[i]}}} \\ [\alpha_{\eta_{A_{j[i]}}}, \alpha_{\eta_{A_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}) && \note{random effect distributions for logit} \\ [\alpha_{\eta_{D_{j[i]}}}, \alpha_{\eta_{D_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}) \\ c &\sim Beta(\mu_{C_i} \phi_{C_i}, (1 - \mu_{C_i}) \phi_{C_i}) && \note{continuous component for compromise} \\ \mu_{C_i} &= \alpha_{\mu_C} + \alpha_{\mu_{C_{j[i]}}} + \alpha_{\mu_{C_{k[i]}}} && \note{linear model for each Beta parameter} \\ \phi_{C_i} &= \alpha_{\phi_C} + \alpha_{\phi_{C_{j[i]}}} + \alpha_{\phi_{C_{k[i]}}} \\ [\alpha_{\mu_{C_{j[i]}}}, \alpha_{\mu_{C_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}) && \note{random effect distributions for Beta} \\ [\alpha_{\phi_{C_{j[i]}}}, \alpha_{\phi_{C_{k[i]}}}] &\sim Normal(0, [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}]) \end{aligned} \]

Methods

Data

For this work, we used data already collected for a different metaanlaysis focused on gender effects in advice-taking. More details on the methods of data collection and the other metaanalysis are in (Kausel et al., 2024). This full dataset had [over 300,000] observations of advice-taking trials from N_people people on N_items different items from N_studies studies.

All of the studies included in the dataset came from JAS designs, meaning participants were asked for both their initial and final judgements. Along with the values of the advice given on each trial, we could calculate WOA for each observations. We removed cases that had missing values for either the initial and final judgements. We also removed cases that happened to have provided exactly the same initial judgement as the advice (\(J_1 = A\)), meaning the denominator of the WOA calculation was zero1.

The data also included multiple potential predictors of advice-taking at the trial-, person-, and study-level (no predictors varied at the item-level). The only trial-level predictor we included was advice distance: the distance between the judge’s initial judgement and the advice, calculated as \(| J_1 - A |\). At the person-level, we included participant age and gender as predictors. We included five study-level predictors. We included an indicator for whether the study used “almanac” items (i.e., asking for judgements on facts about the world, like the distance between two cities), and an indicator for studies using “future” items (i.e., asking for predictions about the future, like the price of gas in three months). We also included indicators for if the advice given was said to come from an expert, whether the study’s data was collected from a student population, and whether the study offered an incentive to participants. We removed observations with missing data on any of the predictors, leaving a dataset with [over 200,000] observations of advice-taking trials from N_people people on N_items different items from N_studies studies.

Dual-Hurdle Metaanalysis Model

To conduct this metaanalysis, we extended Himmelstein’s (2023) dual-hurdle model into a metaanalytic model by adding random effects to capture study-level variation. In this notation, \(i\) indexes each JAS trial, \(j\) indexes each person, \(k\) indexes each item, and \(s\) indexes each study. The unconditional form of the model is:

\[ \begin{aligned} \text{WOA}_i &= \begin{cases} \begin{array}{l} 1 \text{ with } p = \eta_{A_i}\\ 0 \text{ with } p = \eta_{D_i} \\ c \text{ with } p = 1 - \eta_{A_i} - \eta_{D_i} \end{array} \end{cases} && \note{probabilities for each outcome} \\ \text{logit}(\eta_{A_i}) &= \alpha_{\eta_A} + \alpha_{\eta_{A_{j[i]}}} + \alpha_{\eta_{A_{k[i]}}} + \alpha_{\eta_{A_{s[i]}}} && \note{logit models with random effects} \\ \text{logit}(\eta_{D_i}) &= \alpha_{\eta_D} + \alpha_{\eta_{D_{j[i]}}} + \alpha_{\eta_{D_{k[i]}}} + \alpha_{\eta_{D_{s[i]}}} \\ [\alpha_{\eta_{A_{j[i]}}}, \alpha_{\eta_{A_{k[i]}}}, \alpha_{\eta_{A_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}]) && \note{random effect distributions for logit} \\ [\alpha_{\eta_{D_{j[i]}}}, \alpha_{\eta_{D_{k[i]}}}, \alpha_{\eta_{D_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}]) \\ c &\sim Beta(\mu_{C_i} \phi_{C_i}, (1 - \mu_{C_i}) \phi_{C_i}) && \note{continuous component for compromise} \\ \mu_{C_i} &= \alpha_{\mu_C} + \alpha_{\mu_{C_{j[i]}}} + \alpha_{\mu_{C_{k[i]}}} + \alpha_{\mu_{C_{s[i]}}} && \note{linear model for each Beta parameter} \\ \phi_{C_i} &= \alpha_{\phi_C} + \alpha_{\phi_{C_{j[i]}}} + \alpha_{\phi_{C_{k[i]}}} + \alpha_{\phi_{C_{s[i]}}} \\ [\alpha_{\mu_{C_{j[i]}}}, \alpha_{\mu_{C_{k[i]}}}, \alpha_{\mu_{C_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}]) && \note{random effect distributions for Beta} \\ [\alpha_{\phi_{C_{j[i]}}}, \alpha_{\phi_{C_{k[i]}}}, \alpha_{\phi_{C_{s[i]}}}] &\sim Normal(0, [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}]) \\ \\ \alpha_{\eta_A}, \alpha_{\eta_D} &\sim Normal(0, 5) && \note{priors on population means} \\ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects} \\ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \alpha_{\mu_C}, \alpha_{\phi_C} &\sim Normal(0, 5) && \note{priors on population means} \\ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects} \\ [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \end{aligned} \]

Adding in a matrix of predictors to the model, the form is:

\[ \begin{aligned} \text{WOA}_i &= \begin{cases} \begin{array}{l} 1 &\text{ with } p = \eta_{A_i}\\ 0 &\text{ with } p = \eta_{D_i} \\ c &\text{ with } p = 1 - \eta_{A_i} - \eta_{D_i} \end{array} \end{cases} && \note{probabilities for each outcome} \\ \text{logit}(\eta_{D_i}) &= \alpha_{\eta_D} + \boldsymbol{\beta_{\eta_D} X_i} +\alpha_{\eta_{D_{j[i]}}} + \alpha_{\eta_{D_{k[i]}}} + \alpha_{\eta_{D_{s[i]}}} && \note{logit models with random effects} \\ \text{logit}(\eta_{A_i}) &= \alpha_{\eta_A} + \boldsymbol{\beta_{\eta_A} X_i} + \alpha_{\eta_{A_{j[i]}}} + \alpha_{\eta_{A_{k[i]}}} + \alpha_{\eta_{A_{s[i]}}} \\ [\alpha_{\eta_{D_{j[i]}}}, \alpha_{\eta_{D_{k[i]}}}, \alpha_{\eta_{D_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}]) && \note{random effect distributions for logit} \\ [\alpha_{\eta_{A_{j[i]}}}, \alpha_{\eta_{A_{k[i]}}}, \alpha_{\eta_{A_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}]) \\ c &\sim Beta(\mu_{C_i} \phi_{C_i}, (1 - \mu_{C_i}) \phi_{C_i}) && \note{continuous component for compromise} \\ \mu_{C_i} &= \alpha_{\mu_C} + \boldsymbol{\beta_{\mu_C} X_i} + \alpha_{\mu_{C_{j[i]}}} + \alpha_{\mu_{C_{k[i]}}} + \alpha_{\mu_{C_{s[i]}}} && \note{linear model for each Beta parameter} \\ \phi_{C_i} &= \alpha_{\phi_C} + \boldsymbol{\beta_{\phi_C} X_i} + \alpha_{\phi_{C_{j[i]}}} + \alpha_{\phi_{C_{k[i]}}} + \alpha_{\phi_{C_{s[i]}}} \\ [\alpha_{\mu_{C_{j[i]}}}, \alpha_{\mu_{C_{k[i]}}}, \alpha_{\mu_{C_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}]) && \note{random effect distributions for Beta} \\ [\alpha_{\phi_{C_{j[i]}}}, \alpha_{\phi_{C_{k[i]}}}, \alpha_{\phi_{C_{s[i]}}}] &\sim Normal(0, [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}]) \\ \\ \alpha_{\eta_D}, \alpha_{\eta_A} &\sim Normal(0, 5) && \note{priors on population means} \\ \boldsymbol{\beta_{\eta_D}}, \boldsymbol{\beta_{\eta_A}} &\sim Normal(0, \mathbf{b}) \\ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects} \\ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \alpha_{\mu_C}, \alpha_{\phi_C} &\sim Normal(0, 5) && \note{priors on population means} \\ \boldsymbol{\beta_{\mu_C}}, \boldsymbol{\beta_{\phi_C}} &\sim Normal(0, \mathbf{b}) \\ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects} \\ [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \end{aligned} \]

where \(\bf{b}\) is a vector of priors scaled to each predictor and is set to \(3\) for binary predictors.

We estimated the conditional model with Bayesian estimate in Stan, using the cmdstanr package to interface between R and Stan, with 1,000 warmup iterations and 2,500 sampling iterations on each of four chains. We examined model convergence via \(\hat{R}\) values and some visual inspection of trace and tracerank plots. We examined the model performance by comparing the model’s posterior predictive distribution to the distribution of the observed data.

Transition From Dual- to Tri-Hurdle

Tri-Hurdle Model

Estimation on a Single Study

We then extended the model to include an additional hurdle for WOA values of exactly 0.5. First, we implemented this by adding the additional hurdle on a single study’s data (stepping back from the metaanalytic context). With just person- and item-level varying effects, the form of this model is:

\[ \begin{aligned} \text{WOA}_i &= \begin{cases} \begin{array}{l} 0 &\text{ with } p = \eta_{D_i} \\ 0.5 &\text{ with } p = \eta_{M_i} \\ 1 &\text{ with } p = \eta_{A_i} \\ c &\text{ with } p = 1 - \eta_{A_i} - \eta_{D_i} - \eta_{M_i} \end{array} \end{cases} && \note{probabilities for each outcome}\\ \text{logit}(\eta_{D_i}) &= \alpha_{\eta_D} + \alpha_{\eta_{D_{j[i]}}} + \alpha_{\eta_{D_{k[i]}}} \\ \text{logit}(\eta_{M_i}) &= \alpha_{\eta_M} + \alpha_{\eta_{M_{j[i]}}} + \alpha_{\eta_{M_{k[i]}}} && \note{logit models with random effects} \\ \text{logit}(\eta_{A_i}) &= \alpha_{\eta_A} + \alpha_{\eta_{A_{j[i]}}} + \alpha_{\eta_{A_{k[i]}}} \\ [\alpha_{\eta_{D_{j[i]}}}, \alpha_{\eta_{D_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}) \\ [\alpha_{\eta_{M_{j[i]}}}, \alpha_{\eta_{M_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{M_{j[i]}}}, \sigma_{\eta_{M_{k[i]}}}) && \note{random effect distributions for logit} \\ [\alpha_{\eta_{A_{j[i]}}}, \alpha_{\eta_{A_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}) \\ c &\sim Beta(\mu_{C_i} \phi_{C_i}, (1 - \mu_{C_i}) \phi_{C_i}) && \note{continuous component for compromise} \\ \mu_{C_i} &= \alpha_{\mu_C} + \alpha_{\mu_{C_{j[i]}}} + \alpha_{\mu_{C_{k[i]}}} && \note{linear model for each Beta parameter} \\ \phi_{C_i} &= \alpha_{\phi_C} + \alpha_{\phi_{C_{j[i]}}} + \alpha_{\phi_{C_{k[i]}}} \\ [\alpha_{\mu_{C_{j[i]}}}, \alpha_{\mu_{C_{k[i]}}}] &\sim Normal(0, \ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}) && \note{random effect distributions for Beta} \\ [\alpha_{\phi_{C_{j[i]}}}, \alpha_{\phi_{C_{k[i]}}}] &\sim Normal(0, [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}]) \end{aligned} \]

where the \(M\) subscript represents parameters corresponding to the new midpoint hurdle. We again estimated this model in Stan.

Tri-Hurdle Metaanalysis Model

We then converted the tri-hurdle model into a metaanalysis model by adding varying effects at the study level. The conditional form of the model is:

\[ \begin{aligned} \text{WOA}_i &= \begin{cases} \begin{array}{l} 0 &\text{ with } p = \eta_{D_i} \\ 0.5 &\text{ with } p = \eta_{M_i} \\ 1 &\text{ with } p = \eta_{A_i} \\ c &\text{ with } p = 1 - \eta_{A_i} - \eta_{D_i} - \eta_{M_i} \end{array} \end{cases} && \note{probabilities for each outcome} \\ \text{logit}(\eta_{D_i}) &= \alpha_{\eta_D} + \boldsymbol{\beta_{\eta_D} X_i} + \alpha_{\eta_{D_{j[i]}}} + \alpha_{\eta_{D_{k[i]}}} + \alpha_{\eta_{D_{s[i]}}} \\ \text{logit}(\eta_{M_i}) &= \alpha_{\eta_M} + \boldsymbol{\beta_{\eta_M} X_i} + \alpha_{\eta_{M_{j[i]}}} + \alpha_{\eta_{M_{k[i]}}} + \alpha_{\eta_{M_{s[i]}}} && \note{logit models with random effects} \\ \text{logit}(\eta_{A_i}) &= \alpha_{\eta_A} + \boldsymbol{\beta_{\eta_A} X_i} + \alpha_{\eta_{A_{j[i]}}} + \alpha_{\eta_{A_{k[i]}}} + \alpha_{\eta_{A_{s[i]}}} \\ [\alpha_{\eta_{D_{j[i]}}}, \alpha_{\eta_{D_{k[i]}}}, \alpha_{\eta_{D_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}]) \\ [\alpha_{\eta_{M_{j[i]}}}, \alpha_{\eta_{M_{k[i]}}}, \alpha_{\eta_{M_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{M_{j[i]}}}, \sigma_{\eta_{M_{k[i]}}}, \sigma_{\eta_{M_{s[i]}}}]) && \note{random effect distributions for logit} \\ [\alpha_{\eta_{A_{j[i]}}}, \alpha_{\eta_{A_{k[i]}}}, \alpha_{\eta_{A_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}]) \\ c &\sim Beta(\mu_{C_i} \phi_{C_i}, (1 - \mu_{C_i}) \phi_{C_i}) && \note{continuous component for compromise} \\ \mu_{C_i} &= \alpha_{\mu_C} + \boldsymbol{\beta_{\mu_C} X_i} + \alpha_{\mu_{C_{j[i]}}} + \alpha_{\mu_{C_{k[i]}}} + \alpha_{\mu_{C_{s[i]}}} && \note{linear model for each Beta parameter} \\ \phi_{C_i} &= \alpha_{\phi_C} + \boldsymbol{\beta_{\phi_C} X_i} + \alpha_{\phi_{C_{j[i]}}} + \alpha_{\phi_{C_{k[i]}}} + \alpha_{\phi_{C_{s[i]}}} \\ [\alpha_{\mu_{C_{j[i]}}}, \alpha_{\mu_{C_{k[i]}}}, \alpha_{\mu_{C_{s[i]}}}] &\sim Normal(0, \ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}]) && \note{random effect distributions for Beta} \\ [\alpha_{\phi_{C_{j[i]}}}, \alpha_{\phi_{C_{k[i]}}}, \alpha_{\phi_{C_{s[i]}}}] &\sim Normal(0, [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}]) \\ \\ \alpha_{\eta_D}, \alpha_{\eta_M}, \alpha_{\eta_A} &\sim Normal(0, 5) && \note{priors on population means} \\ \boldsymbol{\beta_{\eta_D}}, \boldsymbol{\beta_{\eta_M}}, \boldsymbol{\beta_{\eta_A}} &\sim Normal(0, \mathbf{b}) \\ [\sigma_{\eta_{D_{j[i]}}}, \sigma_{\eta_{D_{k[i]}}}, \sigma_{\eta_{D_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ [\sigma_{\eta_{M_{j[i]}}}, \sigma_{\eta_{M_{k[i]}}}, \sigma_{\eta_{M_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects}\\ [\sigma_{\eta_{A_{j[i]}}}, \sigma_{\eta_{A_{k[i]}}}, \sigma_{\eta_{A_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \alpha_{\mu_C}, \alpha_{\phi_C} &\sim Normal(0, 5) && \note{priors on population means} \\ \boldsymbol{\beta_{\mu_C}}, \boldsymbol{\beta_{\phi_C}} &\sim Normal(0, \mathbf{b}) \\ [\sigma_{\mu_{C_{j[i]}}}, \sigma_{\mu_{C_{k[i]}}}, \sigma_{\mu_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) && \note{priors on variances of cluster effects} \\ [\sigma_{\phi_{C_{j[i]}}}, \sigma_{\phi_{C_{k[i]}}}, \sigma_{\phi_{C_{s[i]}}}] &\sim Student\text{-}t(3, 0, 2.5) \\ \end{aligned} \]

where \(\bf{b}\) once again is a vector of priors scaled to each predictor and is set to \(3\) for binary predictors. We estimated this model in Stan and examined diagnostics.
